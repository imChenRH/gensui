# UWB单基站跟随套件 - 球坐标转三维坐标Excel记录程序

## 功能说明

本程序从UWB基站接收串口数据，将**球坐标（距离、方位角、仰角）转换为三维坐标（X、Y、Z）**，并实时保存到Excel文件中。

### 主要功能

- ✅ 实时接收UWB定位数据
- ✅ 球坐标到三维坐标转换
- ✅ 数据实时保存到Excel文件
- ✅ 自动定期保存（防止数据丢失）
- ✅ 支持模拟模式（无需硬件测试）

## 依赖安装

```bash
pip install pyserial openpyxl
```

## 使用方法

### 1. 查看帮助

```bash
python uwb_excel_logger.py --help
```

### 2. 列出可用串口

```bash
python uwb_excel_logger.py --list
```

### 3. 连接真实硬件

```bash
# 使用默认文件名 uwb_data.xlsx
python uwb_excel_logger.py COM3

# 指定输出文件名
python uwb_excel_logger.py COM3 my_data.xlsx
```

### 4. 模拟模式（无需硬件）

```bash
# 使用默认文件名
python uwb_excel_logger.py --simulate

# 指定输出文件名
python uwb_excel_logger.py --simulate test.xlsx
```

## Excel输出格式

生成的Excel文件包含以下列：

| 列名 | 说明 |
|------|------|
| 序号 | 数据序号 |
| 时间戳 | 记录时间（精确到毫秒） |
| 基站ID | 基站的十六进制ID |
| 标签ID | 标签的十六进制ID |
| 距离(cm) | 原始球坐标距离 |
| 方位角(°) | 原始球坐标方位角 |
| 仰角(°) | 原始球坐标仰角 |
| X坐标(cm) | 转换后的X坐标 |
| Y坐标(cm) | 转换后的Y坐标 |
| Z坐标(cm) | 转换后的Z坐标 |

## 坐标转换公式

```
水平距离 = Distance × cos(Elevation)
X = 水平距离 × sin(Azimuth)
Y = 水平距离 × cos(Azimuth)
Z = Distance × sin(Elevation)
```

### 坐标系定义

```
        Y+ (前方)
        ↑
        |    Z+ (向上)
        |   /
        |  /
 X- ←---+---→ X+ (右侧)
        |
        ↓
        Y- (后方)
```

## 常见问题

### Q: 如何停止记录？
A: 按 `Ctrl+C` 停止记录，程序会自动保存数据并退出。

### Q: 数据多久保存一次？
A: 每接收10条数据自动保存一次，可在代码中修改 `SAVE_INTERVAL` 参数。

### Q: 文件被占用无法保存？
A: 请确保Excel文件没有被其他程序（如Microsoft Excel）打开。
