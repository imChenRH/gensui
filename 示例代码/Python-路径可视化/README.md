# UWB单基站跟随套件 - 路径可视化程序

本目录包含两个可视化程序：

## 程序列表

| 程序 | 说明 |
|------|------|
| `uwb_path_visualizer.py` | 基础版：三个二维平面显示原始数据 |
| `uwb_filtered_visualizer.py` | **对比版（推荐）**：原始数据 vs 滤波数据，含EKF速度估计 |

---

# 1. 基础可视化程序 (uwb_path_visualizer.py)

从UWB基站接收串口数据，实时可视化显示信标的**移动路径**。

### 主要功能

- ✅ 三个二维平面实时显示X、Y、Z坐标
- ✅ 路径渐隐效果：旧路径5秒后自动消失
- ✅ 实时数据显示：距离、方位角、仰角、XYZ坐标
- ✅ 自动调整显示范围

### 使用方法

```bash
# 安装依赖
pip install pyserial matplotlib numpy

# 运行（指定串口）
python uwb_path_visualizer.py COM3
python uwb_path_visualizer.py /dev/ttyUSB0
```

---

# 2. 滤波对比可视化程序 (uwb_filtered_visualizer.py) 【推荐】

**同时显示原始数据和滤波后数据**，用于直观对比滤波效果。

## 滤波流程

程序整合了完整的三步滤波流程：

| 步骤 | 方法 | 说明 |
|------|------|------|
| Step 1 | 物理约束检查 | 范围限制（距离5-5000cm）+ 速度限制（最大300cm/s）|
| Step 2 | 中位数滤波 | 窗口大小5，消除尖峰异常值 |
| Step 3 | EKF状态估计 | 位置平滑 + 速度估计 |

## EKF扩展卡尔曼滤波

### 为什么传感器已有KF还能用EKF？

| 滤波类型 | 作用 | 说明 |
|----------|------|------|
| 传感器KF | 测量级滤波 | 仅平滑单个测量值 |
| EKF | 状态估计滤波 | 结合运动模型预测位置和速度 |

### EKF的优势（机器狗跟随场景）

- ✅ **预测目标运动趋势**：即使短暂丢失数据也能预测位置
- ✅ **估计移动速度**：输出 Vx, Vy, Vz 用于机器狗控制
- ✅ **对突变数据更强抑制**：结合运动模型验证测量合理性
- ✅ **数据丢失时可预测**：使用恒速模型预测未来位置

## 使用方法

```bash
# 安装依赖
pip install pyserial matplotlib numpy

# 运行（指定串口）
python uwb_filtered_visualizer.py COM3
python uwb_filtered_visualizer.py /dev/ttyUSB0

# 查看帮助
python uwb_filtered_visualizer.py --help

# 列出可用串口
python uwb_filtered_visualizer.py --list
```

## 输出数据

### 原始数据
- 距离 (cm)
- 方位角 (度)
- 仰角 (度)
- X, Y, Z 坐标 (cm)

### 滤波后数据
- X, Y, Z 坐标 (cm) - 滤波后的位置
- Vx, Vy, Vz (cm/s) - EKF估计的速度

### 统计信息
- 总数据量
- 异常值数量
- 有效数据量
- 异常率
